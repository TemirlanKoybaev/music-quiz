# 🎵 Music Quiz

Веб-приложение для распознавания музыки. Загрузи аудиофайл — система определит исполнителя и трек.

## Стек технологий

- **Backend:** Java 17, Spring Boot 3.5, Spring Data JPA
- **Frontend:** Thymeleaf, Bootstrap 5
- **База данных:** PostgreSQL
- **Аудио:** JAudioTagger, AudD API
- **Инфраструктура:** Docker

## Возможности

- Загрузка аудиофайлов (MP3, FLAC)
- Распознавание исполнителя и названия трека
- Извлечение технических метаданных файла
- История запросов

## Запуск

```bash
./mvnw.cmd package "-DskipTests"
docker compose up --build
```

Приложение доступно по адресу: `http://localhost:8080`
